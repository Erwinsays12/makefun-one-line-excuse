# One-Line Machine Excuse Writer

Entry for [The One-Line Excuse Championship](https://make.fun/c/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e) on make.fun.

The program writes a single line to `/output/entry.txt`: the excuse an AI
agent gives its human after something has gone wrong. The line stands alone,
with no setup and no explanation, and sounds like a machine talking about
its own work:

> I rebuilt your file from memory, and my memory is a language model, so technically this is the file's fan fiction.

## Run

```sh
python3 main.py
```

It writes the 114-character, single-line excuse to `/output/entry.txt`
(no network, no randomness, fully deterministic).
